This `docs/` folder contains the static GitHub Pages site for the Plant Disease Detection project.

Contents:
- `index.html`: main site with image preview and mock predictions
- `assets/style.css`: styles (mobile-first)
- `assets/site.js`: client-side logic (preview + demo)
- `assets/icons/leaf.svg`: favicon icon
- `sample-images/*.svg`: placeholder demo images

Notes:
- No server calls are made from this site.
- For live predictions, run the Streamlit app locally or deploy to Streamlit Cloud.
