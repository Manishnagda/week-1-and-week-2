Class Labels

    Run Locally

    Run the Streamlit app for live predictions:

    python -m venv venv
source venv/bin/activate   # macOS/Linux
venv\Scripts\activate      # Windows
pip install -r requirements.txt
streamlit run main.py      # or: streamlit run app.py

    Deploy Online (optional)

    • Streamlit Cloud: Push your repo and deploy. Add secrets/files as needed.
    • Heroku: Containerize or use buildpacks, then run streamlit run app.py on web dyno.

    This static site cannot run TensorFlow/Keras. For live inference, run Streamlit locally or deploy to a cloud service.

    Convert Keras .h5 to TensorFlow.js (optional)

    You can convert the trained Keras model for client-side inference with TFJS:

    pip install tensorflowjs
tensorflowjs_converter --input_format keras \
  model/plant_disease_model.h5 \
  docs/assets/tfjs-model

    Once converted, wire TFJS in assets/site.js to run client-side predictions.
